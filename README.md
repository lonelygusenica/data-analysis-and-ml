# Инструменты анализа данных

Здесь собраны практические работы по анализу данных и машинному обучению за два семестра. Основная часть решений оформлена в Jupyter Notebook, отдельные алгоритмы реализованы на Python.

## Структура

| Папка | Содержание |
| --- | --- |
| `1 sem/1 task` | Разведочный анализ и подготовка данных об автомобилях. |
| `1 sem/2 task` | Прогнозирование продаж во временных рядах. |
| `1 sem/3 task` | Анализ данных по вакансиям. |
| `1 sem/6 task` | Работа с данными онлайн-курсов и парсинг. |
| `2 sem/1-1 task` | Своя реализация KNN. |
| `2 sem/1-2 task` | Линейная и полиномиальная регрессия. |
| `2 sem/1-3 task` | Своя реализация дерева решений. |
| `2 sem/1-4 task` | Ансамблевые методы: bagging и random forest. |
| `2 sem/1-5 task` | Кластеризация K-Means и DBSCAN. |
| `2 sem/2-1 task` | Кластеризация вузов. |
| `2 sem/2-2 task` | Кластеризация книг по названиям и описаниям. |
| `2 sem/3-1 task` | Полносвязные сети Keras на MNIST. |
| `2 sem/3-2 task` | Свёрточные сети Keras на CIFAR-10. |
| `2 sem/3-3 task` | Полносвязные сети PyTorch на MNIST. |
| `2 sem/3-4 task` | Свёрточные сети PyTorch на CIFAR-10. |
| `2 sem/3-5 task` | Классификация цветов, аугментация и предобученная модель. |
| `2 sem/3-7 task` | Семантическая сегментация изображений. |
| `2 sem/3-8 task` | Подсчёт клеток крови и OOD-детекция. |
| `2 sem/lec` | Домашняя работа с текстовыми признаками. |

Тексты части заданий находятся в файле `tasks.txt` в корне проекта.

## Как открыть работы

Для просмотра ноутбуков нужен Jupyter Notebook или JupyterLab. Основные библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `tensorflow`, `torch`, `torchvision`, `catboost`.

Датасеты и результаты обучения лежат рядом с соответствующими работами. Некоторые задания требуют предварительно скачать исходные данные с Kaggle или через библиотеки `torchvision` и `tensorflow`.

## Примечание перед загрузкой на GitHub

GitHub не принимает отдельные файлы больше 100 МБ. В `.gitignore` добавлены три таких файла: обученная модель, архив CIFAR-10 и большой файл с данными продаж. Они остаются на компьютере и не изменяются. При необходимости их можно хранить отдельно через Git LFS или скачать заново из источника.
