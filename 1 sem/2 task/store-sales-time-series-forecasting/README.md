# Прогнозирование продаж магазинов

В работе рассматривается задача прогноза продаж по дням для сети магазинов. Данные о продажах объединены с информацией о магазинах, праздниках, ценах на нефть и количестве транзакций.

Были подготовлены признаки даты, обработаны категориальные данные и обучены несколько моделей регрессии: линейная регрессия, Ridge, дерево решений и HistGradientBoosting. Результаты моделей сравнивались на отложенной выборке.

Использованы `pandas` и `scikit-learn`. Работа помогает разобраться, как готовить временные данные и добавлять внешние признаки в прогноз.
