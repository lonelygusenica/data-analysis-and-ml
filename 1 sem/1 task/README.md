# Анализ цен на автомобили

В работе выполнен разведочный анализ датасета с объявлениями о подержанных автомобилях. Целью было подготовить данные к дальнейшему построению модели цены.

Были изучены числовые и категориальные признаки, пропуски, выбросы и зависимости между данными. Для категорий выбрано кодирование, признаки нормализованы, а размерность уменьшена методом главных компонент.

Использованы `pandas`, `matplotlib`, `seaborn` и `scikit-learn`. Работа показывает базовый процесс подготовки табличных данных для задачи машинного обучения.
