# Анализ онлайн-курсов Coursera

В работе исследуются данные об онлайн-курсах Coursera и решается задача предсказания числового показателя курса по его описанию и характеристикам.

Текстовые поля преобразованы через TF-IDF, а числовые и категориальные признаки подготовлены в общем пайплайне. Были проверены Ridge, Random Forest, Gradient Boosting, CatBoost и LightGBM.

В папке также находятся скрипты для сбора данных. Работа объединяет парсинг, обработку текста и сравнение моделей регрессии.
