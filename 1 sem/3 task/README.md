# Анализ вакансий в Data Science

В работе собраны и проанализированы вакансии Data Analyst, Data Engineer, Data Scientist и Business Analyst. Целью было найти похожие группы вакансий по их описанию и навыкам.

Текстовые признаки были очищены и преобразованы через TF-IDF. Затем применены K-Means, иерархическая кластеризация и DBSCAN. Для оценки разбиения использовались визуализации и silhouette score.

Использованы `pandas`, `scikit-learn` и `scipy`. Работа показывает применение обработки текста и кластеризации к данным рынка труда.
