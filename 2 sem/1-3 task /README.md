# Своя реализация дерева решений

В работе реализовано дерево решений для классификации. Алгоритм выбирает разбиения признаков и последовательно делит объекты на более однородные группы.

Работа модели проверяется на датасете и сопоставляется с библиотечной версией из `scikit-learn`. В ноутбуке можно посмотреть, как параметры дерева влияют на качество и переобучение.

Работа помогает понять базовую логику деревьев решений и подготовку данных для классификации.
