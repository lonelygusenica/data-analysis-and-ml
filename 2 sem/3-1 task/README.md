# Полносвязные сети Keras на MNIST

В работе построены несколько полносвязных нейронных сетей для распознавания рукописных цифр MNIST.

Менялось число слоёв и размер скрытых слоёв, после чего модели обучались и сравнивались по качеству. Результаты обучения и предсказания визуализированы в ноутбуке.

Использованы `Keras` и `TensorFlow`. Работа знакомит с базовым циклом обучения нейросети и сравнением архитектур.
