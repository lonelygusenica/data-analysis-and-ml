# Полносвязные сети PyTorch на MNIST

В работе реализованы несколько полносвязных нейросетей на PyTorch для классификации цифр MNIST.

Данные разделены на обучающую, валидационную и тестовую части. Были проверены разные размеры слоёв, функции активации и настройки обучения.

Работа знакомит с `torch`, `DataLoader`, обучающим циклом и сравнением нескольких моделей.
