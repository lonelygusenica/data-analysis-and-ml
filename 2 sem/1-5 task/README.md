# Своя реализация алгоритмов кластеризации

В работе реализованы алгоритмы K-Means и DBSCAN. Они применяются к данным, а результаты сравниваются с реализациями из `scikit-learn`.

Для K-Means реализованы выбор центроидов и пересчёт кластеров. Для DBSCAN рассмотрены плотностные кластеры, шумовые точки и влияние параметров алгоритма.

Работа помогает понять разницу между кластеризацией по центрам и кластеризацией по плотности.
