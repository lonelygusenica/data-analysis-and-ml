# Семантическая сегментация автомобилей

В работе используется датасет Carvana Image Masking. Задача состоит в том, чтобы для каждого изображения автомобиля получить маску объекта.

Данные были подготовлены и дополнены синхронной аугментацией изображений и масок. Обучалась U-Net, сравнивались функции потерь BCE и Dice Loss, а качество оценивалось по IoU и Dice.

Работа показывает основы сегментации изображений и работу с масками в нейросетях.
