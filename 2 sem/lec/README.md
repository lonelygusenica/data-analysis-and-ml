# Работа с текстовыми эмбеддингами

В работе используются готовые текстовые эмбеддинги и размеченные данные. На их основе обучается модель для задачи классификации.

Подготовленные векторы подаются в модель, после чего оцениваются её предсказания. Это пример работы с текстовыми признаками без ручного построения словаря.

Работа показывает, как применять эмбеддинги как входные данные для классических моделей машинного обучения.
