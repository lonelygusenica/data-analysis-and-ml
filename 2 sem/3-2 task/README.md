# Свёрточные сети Keras на CIFAR-10

В работе сравниваются несколько свёрточных нейросетей для классификации изображений из CIFAR-10.

Проверены простая CNN, более глубокая модель с Dropout и вариант с Batch Normalization. Для каждой модели построены графики обучения и выполнена оценка на тестовых данных.

Работа показывает, как изменение архитектуры влияет на обучение и переобучение свёрточной сети.
