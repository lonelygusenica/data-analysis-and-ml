# Классификация цветов

В работе решается задача классификации фотографий цветов. Были проверены полносвязная сеть, свёрточная сеть и предобученная модель.

Для улучшения качества использованы аугментации, собственные изображения и изображения, созданные вручную или генеративными средствами. Отдельно рассматриваются ошибочные предсказания моделей.

Работа показывает, как подготовить набор изображений, обучить модель и проверить её на новых данных.
