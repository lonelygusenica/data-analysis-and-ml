# Свёрточные сети PyTorch на CIFAR-10

В работе построены и сравнены свёрточные сети PyTorch для классификации изображений CIFAR-10.

Для обучения добавлены преобразования и аугментация изображений. В ноутбуке рассматриваются несколько архитектур, ранняя остановка, графики обучения и ошибки классификации.

Работа показывает практический процесс обучения CNN и способы уменьшить переобучение.
