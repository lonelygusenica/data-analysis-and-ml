# Своя линейная и полиномиальная регрессия

В работе реализованы классы линейной и полиномиальной регрессии. Они обучаются на данных и строят предсказания без использования готовой модели регрессии.

Реализация проверяется сравнением с методами из `scikit-learn` на датасете автомобилей. Отдельно показано, как полиномиальные признаки позволяют описывать нелинейную зависимость.

Работа закрепляет основы регрессии, подготовки признаков и оценки предсказаний.
