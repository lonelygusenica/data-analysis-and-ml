# Кластеризация вузов

В работе анализируются показатели российских вузов за несколько лет. Данные очищаются, исследуются пропуски и подбираются признаки для кластеризации.

Было проверено несколько вариантов числа кластеров и оценено, какие группы вузов можно интерпретировать по их показателям. Также использованы данные предыдущих лет.

Использованы `pandas`, `scikit-learn` и визуализация. Работа показывает полный процесс кластеризации табличных данных.
