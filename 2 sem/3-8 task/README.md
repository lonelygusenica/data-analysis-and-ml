# Автоматизация микроскопии

В работе рассматривается датасет BCCD с изображениями клеток крови. Нужно определить количество клеток разных классов на изображении.

Проверены два подхода: прямое предсказание количества клеток моделью ResNet50 и подсчёт объектов по результатам YOLO. Также добавлена OOD-детекция для размытых, шумных и других непохожих изображений.

Работа объединяет анализ изображений, регрессию, детекцию объектов и проверку модели на нестандартных данных.
