# Кластеризация книг по тексту

В работе книги группируются по названиям и кратким описаниям. Перед кластеризацией изучены пропуски, распределение жанров и длина текстов.

Тексты векторизованы методами CountVectorizer и TF-IDF. Затем были проверены K-Means, n-граммы и разные настройки признаков, а кластеры визуализированы и сопоставлены с жанрами.

Работа показывает, как текст превращается в признаки для моделей машинного обучения.
