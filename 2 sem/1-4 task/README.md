# Ансамбли моделей

В работе реализованы собственные классы bagging и random forest. Для базовых моделей используются деревья решений из `scikit-learn`.

Модели обучаются на случайных подвыборках данных и признаков, после чего их предсказания объединяются. Это позволяет сравнить одиночное дерево и ансамбль деревьев.

Работа показывает, как ансамбли уменьшают нестабильность модели и зачем нужна случайность при обучении леса.
