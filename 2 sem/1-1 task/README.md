# Своя реализация KNN

В работе реализован алгоритм классификации k ближайших соседей без использования готовой модели `scikit-learn`.

Класс рассчитывает расстояния до объектов обучающей выборки, выбирает ближайших соседей и определяет класс голосованием. Результат сравнивается с библиотечной реализацией на одном наборе данных.

Работа нужна для понимания того, как устроен KNN внутри и как влияют выбор расстояния и число соседей.
